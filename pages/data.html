📍 Où sont stockées les données ?

Les données sont stockées dans MongoDB via l'API du serveur.

Cela signifie que :

  • Les données sont centralisées sur le serveur
  • Elles sont partagées entre les navigateurs et les machines autorisés
  • Le navigateur ne conserve plus la base métier localement
  • Les suppressions passent désormais par l'API et la base MongoDB
