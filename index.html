Gestion des Données

📍 Où sont stockées les données ?

Les données sont stockées dans le localStorage de votre navigateur.

Cela signifie que :

  • Les données sont stockées localement sur votre ordinateur
  • Elles sont spécifiques à ce navigateur (Chrome, Firefox, Edge, etc.)
  • Elles persistent même après la fermeture du navigateur
  • Si vous supprimez les données du navigateur, vous perdrez toutes les données

⚠️ Important : Pour ne pas perdre vos données, utilisez les fonctions d'export ci-dessous pour créer une sauvegarde.
